# НТО · Корпоративная кибербезопасность 2026

Командная организация для отборочного этапа студенческого трека НТО
(17.11–15.12.2026). Пять ролей, один процесс, автоматические гейты качества.

## Роли

| Роль | Команда | Зона ответственности |
|---|---|---|
| TeamLead / OSINT / аналитика | `@nto-corpsec/leads`, `@nto-corpsec/osint` | Приоритеты, ревью, разведка, сводки, сдача |
| Социальная инженерия | `@nto-corpsec/soceng` | Фишинг, претекстинг, OSINT по людям |
| Инженер по восстановлению данных | `@nto-corpsec/dfir` | Форензика, артефакты, рекавери |
| Сетевая безопасность | `@nto-corpsec/netsec` | pcap, IDS/NSM, карта сети |
| Web-безопасность | `@nto-corpsec/websec` | Уязвимости веб-приложений, эксплуатация |

## Репозитории

| Репозиторий | Что внутри | Доступ |
|---|---|---|
| [`hub`](https://github.com/nto-corpsec/hub) | Playbook, runbook, ADR, доска | все |
| [`arsenal`](https://github.com/nto-corpsec/arsenal) | Инструменты, Python-пакет `nto`, CI | все |
| [`lab`](https://github.com/nto-corpsec/lab) | Стенды: Wazuh, Juice Shop, сенсоры | все |
| [`ops`](https://github.com/nto-corpsec/ops) | Ответы, флаги, сырые доказательства | только команда, приватно |
| `tpl-*` | Шаблоны новых репозиториев | все |

## С чего начать

1. Прочитай [`hub/docs/PLAYBOOK.md`](https://github.com/nto-corpsec/hub/blob/main/docs/PLAYBOOK.md).
2. Создай рабочую ветку от `main`, не пушь в `main` напрямую.
3. Любое изменение — через Pull Request с зелёным CI и одним ревью.
4. Флаги, ответы и сырые артефакты — **только** в приватный `ops`.

## Правила безопасности

- В публичных репозиториях нет секретов, флагов, персональных данных и сырых дампов.
- Сторонние GitHub Actions закреплены по commit SHA.
- `GITHUB_TOKEN` по умолчанию имеет только `contents: read`.
